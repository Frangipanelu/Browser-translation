Obsidian 术语表（Glossary）

术语表 = 你精选的"专业术语 / 地道表达"，每条写成一个独立笔记，存进仓库的 Glossary 文件夹，可用 Dataview 按出处/类型/标签查询。 填仓库名称（Obsidian 左侧显示的文字），不是文件夹路径！例如 "Knowledge"，不要填 "D:\obsidian\..." 仅 rest 模式需要。Obsidian 装 Local REST API 插件后，默认端口 27123。
